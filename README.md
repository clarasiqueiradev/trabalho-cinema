# trabalho-cinema

Sistema de reservas de cinema em Java, feito só com funções (métodos `static`) e sem Orientação a Objetos.

## Como rodar

```
javac -encoding UTF-8 Cinema.java
java Cinema
```

Ao iniciar, o programa pede o valor do ingresso, a quantidade de fileiras e de assentos por fileira (de 5 a 25).

## Arquivos

- `Cinema.java`: código-fonte completo
- `reservas.csv`: arquivo de reservas de exemplo para a opção 1 (formato `Assento,Sexo,Idade`)

## Antes de entregar

Edite a lista `INTEGRANTES`, no começo do `Cinema.java`, com os nomes do grupo.
